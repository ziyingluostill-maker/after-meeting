# 会议录音 → 纪要（待办导向）

用户发来会议录音时：**直接转写并产出纪要**，重点是可执行待办，不是流水账。

## 产出目标（必须覆盖）

1. **要干什么**：具体事项（可验收）
2. **谁干**：负责人；多人则写主责 + 协作
3. **DDL**：明确日期/相对时间；录音未提则写「待确认」并标出依据缺口
4. **计划怎么样**：阶段、依赖、上线/里程碑、阻塞点

附带：讨论结论、待拍板事项、原文转写备份。

## 工作流（按序执行）

复制进度并勾选：

```
- [ ] 1. 确认音频路径与语言
- [ ] 2. 转写（scripts/transcribe_audio.py）
- [ ] 3. 抽取待办/计划/结论
- [ ] 4. 写 Excel + 转写原文
- [ ] 5. 简短回复路径与关键待确认项
```

### 1. 音频与语言

- 默认语言：`zh`（普通话）。用户说粤语/Cantonese → `--language yue` 或先 `zh` 再据效果调整。
- 用户未说明语言且口音可能混杂：先 `medium` + `zh`；明显不对再按用户纠正重跑。
- 长会（>30min）可先 `small` 出草稿，再对关键段或全量用 `medium` 精转。
- 工作目录：`/tmp/mtg_minutes_<短名>/`，勿污染用户桌面中间文件。

### 2. 转写

本机常用：`afconvert`（无 ffmpeg）、`python3 -m whisper` 经 numpy 读 WAV（Whisper 内置 ffmpeg 加载常失败）。

脚本路径相对本 skill 目录（插件安装后由 Agent 定位 skill 根目录）：

```bash
python3 scripts/transcribe_audio.py \
  "/path/to/recording.m4a" \
  --out-dir /tmp/mtg_minutes_xxx \
  --model medium \
  --language zh
```

若相对路径找不到，用 skill 目录的绝对路径调用同一脚本。

- 需要长时间跑：Shell `block_until_ms` 设够（medium 约 10min+/小时音频），或后台跑并轮询输出。
- 转写完成后读 `transcript.txt`；**不要把整篇原文贴进对用户回复**，只落盘。

### 3. 抽取规则

从转写中提炼，禁止编造人名/日期：

| 字段 | 规则 |
|------|------|
| 事项 | 改成「动词 + 对象」；合并重复；拆开捆在一起的多件事 |
| 负责人 | 录音里的称呼原样保留；未提 →「待指定」 |
| DDL | 保留「下周三 / 12月上旬 / 上线前」等原话，并尽量换算为具体日期（今天以对话中的 Today 为准）；无法换算 → 原话 +「待确认」 |
| 优先级 | 若有「先做/卡住/必须」→ 高；其余默认中 |
| 计划 | 里程碑、分阶段、依赖他人、与产品/上线相关的节点单独成行或写入计划 sheet |

另列：

- **待拍板**：有争议或「再看看」的决策
- **仅知会**：无行动项的结论（可短）

### 4. 交付物

默认目录（用户可改）：

- 用友/香港相关 → `~/Desktop/香港用友/`
- 其他 → `~/Desktop/会议纪要/` 或用户指定路径

文件：

1. `会议纪要_<主题或文件名>.xlsx`
2. `会议纪要_<主题或文件名>_转写原文.txt`

#### Excel 三表结构

**Sheet「行动项」**（主表，必有）

| 列 | 说明 |
|----|------|
| 序号 | 1…n |
| 事项 | 要干什么 |
| 负责人 | 谁干 |
| DDL | 截止日期/节点 |
| 优先级 | 高/中/低 |
| 状态 | 默认「未开始」；录音已说完成则「已完成」 |
| 依赖/阻塞 | 可选 |
| 备注 | 原话要点、上下文 |

**Sheet「计划与里程碑」**

| 列 | 说明 |
|----|------|
| 阶段/里程碑 | 如「内容定稿」「提测」「上线」 |
| 目标日期 | 有则填，无则待确认 |
| 相关行动项 | 序号或简述 |
| 说明 | 计划怎么走、风险 |

**Sheet「结论与待拍板」**

| 列 | 说明 |
|----|------|
| 类型 | 结论 / 待拍板 / 风险 |
| 内容 | 一句话 |
| 相关方 | 可选 |

用 `openpyxl` 写表；**不要**对 `StyleProxy` 做 `.font = cell.font` 之类复制，新建 `Font(bold=True)` 即可。表头加粗、列宽适中。

专题会（如官网改版）可在「行动项」后加自定义列（模块、页面），或增加业务 sheet，但**不得缺少**行动项三要素：事项 / 负责人 / DDL。

### 5. 回复用户

极简：

- 文件路径（xlsx + 转写）
- 行动项条数 + 仍「待确认」的 DDL/负责人条数
- 最多 3 条关键待拍板（若有）

长会转写未完成时：先说「转写进行中」，完成后再交纪要；用户问「行不行」→ 直接报进度。

## 质量检查

- [ ] 每条行动项都能回答「谁、做什么、何时」
- [ ] 未在录音出现的人名/日期未写入（除非标「待确认」）
- [ ] 计划 sheet 覆盖了上线/阶段类讨论
- [ ] 转写原文已保存；回复未刷屏贴全文

## 本机约束（勿重复踩坑）

- 无系统 `whisper` CLI / 常无 `ffmpeg` → 用脚本 + `afconvert`
- `import whisper` + CPU `medium` 即可；勿假设 GPU
- Desktop 写入需足够权限（必要时 `all`）
